## Module Interface

### Initialization
```javascript
// In WavelengthRadio.init()
this.screensaver = new RadioScreenSaver(this);
```

### Usage
```javascript
// Check if active
if (this.screensaver?.active) {
    this.screensaver.updateImages();
}

// Toggle
this.screensaver.toggle();
```
