WHAT IS THIS?
═════════════════════════════════════════════════════════════════════════════════

Browser-based automated tests for the Merch Store that verify:
  ✓ Customization dialog works
  ✓ Preview opens without alerts
  ✓ Back button restores state
  ✓ Modals close properly
  ✓ No console errors

Tests the EXACT workflow you described:
  1. Open Merch Store
  2. Select image → Choose product
  3. Customization dialog opens ✓
  4. Select effects → Click "Update Preview" ✓
  5. Click "Preview Finished Product" ✓ (NO ALERT!)
  6. Click "Back to Customize" ✓
  7. Customization reappears with selections intact ✓
  8. Press Escape in preview ✓
  9. Modal closes ✓

INSTALLATION
═════════════════════════════════════════════════════════════════════════════════

1. Install Puppeteer:
   npm install puppeteer

RUNNING THE TESTS
═════════════════════════════════════════════════════════════════════════════════

SETUP:
  Terminal 1: npm start
  (Wait for server to start)

TEST:
  Terminal 2: node tests/merch-store-e2e.test.js

THAT'S IT! ✅

COMMON COMMANDS
═════════════════════════════════════════════════════════════════════════════════

See browser run tests:
  HEADLESS=false node tests/merch-store-e2e.test.js

Slow down for observation:
  HEADLESS=false SLOW_MO=500 node tests/merch-store-e2e.test.js

Custom server URL:
  BASE_URL=http://localhost:5000 node tests/merch-store-e2e.test.js

Add to package.json scripts section:
  "test:merch": "node tests/merch-store-e2e.test.js",
  "test:merch:debug": "HEADLESS=false SLOW_MO=500 node tests/merch-store-e2e.test.js"

Then run:
  npm run test:merch
  npm run test:merch:debug

  12. Presses Escape

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

PROBLEM: "connect ECONNREFUSED"
SOLUTION: Start server: npm start

PROBLEM: "Tests timeout after 30000ms"
SOLUTION: Slow down and watch: SLOW_MO=500 node tests/merch-store-e2e.test.js

PROBLEM: "Element not found"
SOLUTION: See browser: HEADLESS=false SLOW_MO=1000 node tests/merch-store-e2e.test.js
           Check that selectors match your HTML structure

PROBLEM: "Port 3000 already in use"
SOLUTION: lsof -ti:3000 | xargs kill -9
          then: npm start

PROBLEM: "Cannot find module 'puppeteer'"
SOLUTION: npm install puppeteer
