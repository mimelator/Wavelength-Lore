# Wavelength Gems - Player Quick Start Guide

## 🎮 Welcome to Wavelength Gems!

**Wavelength Gems** is a magical match-3 puzzle game where each level tells a story from the **Wavelength Lore** series. Match colorful gems themed after beloved characters while experiencing epic adventures across the Wavelength universe!

## 🚀 Getting Started

### How to Access the Game
1. **VIP Access Required** - You need VIP or higher tier access to play
2. **Navigate to Games** - Visit `/games` from the main Wavelength site
3. **Select Wavelength Gems** - Click on the game to start your adventure!

### First Time Playing
When you start the game for the first time:
- You'll begin with **Level 1: "My Lucky Charm"** 
- Watch the **level briefing** to understand the story context
- The game includes a **gentle tutorial** to learn the mechanics

## 🎯 How to Play

### Basic Gameplay
1. **Select a Gem** - Click or tap on any gem to highlight it
2. **Choose Adjacent Gem** - Click a neighboring gem (up, down, left, right) to swap
3. **Make Matches** - Line up 3 or more identical gems horizontally or vertically
4. **Watch Magic Happen** - Matched gems disappear, new ones fall down
5. **Create Cascades** - New gems can create additional matches for bonus points!

### Game Controls
- **Click/Tap** - Select and swap gems
- **📋 Select Level** - Choose which level to play
- **↻ Restart Level** - Try the current level again  
- **⏸ Pause** - Pause the game
- **🔊 Sound Toggle** - Turn sound on/off
- **🏆 Leaderboard** - View top scores

## 🎪 Game Features

### Level Progression
- **Episode-Based Levels** - Each level tells part of a Wavelength Lore episode
- **Increasing Difficulty** - Levels get more challenging as you progress
- **Multiple Seasons** - Play through Seasons 1, 2, 3, and upcoming Season 4

### Scoring System
- **Basic Match** - 100 points for 3 gems
- **Larger Matches** - More points for 4+ gem matches
- **Cascade Bonus** - Extra points when new matches form automatically
- **Combo Multiplier** - Chain reactions increase your score multiplier
- **Move Efficiency** - Bonus points for completing levels with moves remaining

### Level Objectives
Each level has specific goals to achieve:
- **Score Targets** - Reach a minimum point threshold
- **Move Limits** - Complete objectives within allowed moves
- **Cascade Requirements** - Create a certain number of chain reactions
- **Special Challenges** - Episode-specific objectives

## 🏆 Strategy Tips

### Beginner Strategies
1. **Look for Cascades** - Try to create matches that will cause chain reactions
2. **Plan Ahead** - Think about what happens after you make a match
3. **Use All Gem Types** - Don't focus on just one color
4. **Corner Strategy** - Matches in corners often create good cascades
5. **Count Your Moves** - Keep track of remaining moves

### Advanced Techniques  
1. **Cascade Chaining** - Set up multiple cascade sequences
2. **Board Reading** - Analyze the entire board before making moves
3. **Score Optimization** - Prioritize high-scoring combo opportunities
4. **Move Conservation** - Achieve objectives with moves to spare
5. **Pattern Recognition** - Learn common board configurations

### Level-Specific Tips
- **Score Challenges** - Focus on large matches and cascades
- **Move Limits** - Plan carefully, every move counts
- **Cascade Goals** - Look for L and T-shaped match opportunities
- **Episode Themes** - Pay attention to story context for inspiration
