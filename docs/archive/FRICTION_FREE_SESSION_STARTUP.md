## TROUBLESHOOTING

### If Session Startup Fails:
1. Verify Node.js is available
2. Check `wavelength-tools/` directory exists
3. Ensure write permissions for session files
4. Run with debug: `NODE_ENV=debug node start-wavelength-session.js`

### Common Issues:
- **Missing AI Context**: Will create new context automatically
- **No Super Powers Found**: Check `wavelength-tools/` directory
- **Permission Errors**: Ensure write access to project directory
