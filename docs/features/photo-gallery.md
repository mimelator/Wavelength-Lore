# Photo Gallery Feature

## Overview
This feature allows users to capture copies of any images they see while browsing the Wavelength Lore site and save them to their personal gallery. From there, users can download, view, or display the images as a screensaver.

## Planned Functionality
- Ability to "capture" images from anywhere on the site (carousels, /radio page screensaver, forum pages, etc.)
- Personal gallery to store and manage captured images
- Display captured images in grid, carousel, or masonry layouts
- Support for image enlargement/lightbox view
- Image navigation (next/previous)
- Download functionality for saved images
- Screensaver mode for displaying gallery images
- Responsive design for various screen sizes
- Integration with existing content system
