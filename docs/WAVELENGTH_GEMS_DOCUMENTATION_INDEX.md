# Wavelength Gems - Documentation Index

## 📚 Overview

This directory contains comprehensive documentation for **Wavelength Gems**, a narrative-driven match-3 puzzle game integrated into the Wavelength ecosystem. Each document serves a specific audience and purpose.

## 🚀 Getting Started Workflows

### I'm a Developer
```
1. Read Developer Guide (Architecture Overview)
2. Set up development environment
3. Use admin panel (Ctrl+Shift+D) to explore
4. Review existing level configurations
5. Start contributing!
```

### I'm a Level Designer  
```
1. Read Game Design Document (Design Philosophy)
2. Study Level Creation Guide (YAML system)
3. Examine existing levels in wavelength-gems-levels.yaml
4. Create test level using admin panel
5. Playtest and iterate!
```

### I'm a Player Helping Others
```
1. Read Player Guide thoroughly
2. Play through early levels to understand progression
3. Test mobile experience
4. Share knowledge with community
5. Provide feedback to development team!
```

### I'm a Stakeholder
```
1. Review Game Design Document (Vision & Strategy)
2. Understand monetization philosophy
3. Review community integration approach
4. Examine technical architecture summary
5. Discuss roadmap and priorities!
```
