# AWS Policies and Configuration Files

This directory contains all AWS-related policy documents and configuration files for the Wavelength Lore project.

## 📁 Directory Contents

### 🔐 IAM and Service Policies
- **`apprunner-policy.json`** - AWS App Runner service policy configuration
- **`cloudfront-policy.json`** - CloudFront distribution policy settings

### 🪣 S3 Bucket Policies
- **`cloudfront-only-bucket-policy.json`** - S3 bucket policy allowing only CloudFront access
- **`final-bucket-policy.json`** - Final production S3 bucket policy
- **`temp-bucket-policy.json`** - Temporary bucket policy (development/testing)

### ☁️ CloudFront Configuration Files
- **`cloudfront-config.json`** - Main CloudFront distribution configuration
- **`cloudfront-config-update.json`** - CloudFront configuration updates
- **`cloudfront-backup-updated.json`** - Backup of updated CloudFront configuration
- **`cloudfront-updated-config.json`** - Updated CloudFront distribution settings
- **`updated-cloudfront-config.json`** - Alternative updated CloudFront configuration
- **`current-config.json`** - Current active CloudFront configuration (generated by AWS CLI)
- **`cloudfront-cors-config.json`** - CORS configuration for CloudFront/S3

## 🚀 Usage

### Getting Current CloudFront Configuration
```bash
# Export current configuration from AWS
aws cloudfront get-distribution-config --id E2QFR8E7I4A6ZT --output json > aws-policies/current-config.json
```

### Applying Bucket Policies
```bash
# Apply S3 bucket policy
aws s3api put-bucket-policy --bucket your-bucket-name --policy file://aws-policies/final-bucket-policy.json
```

### Updating CloudFront Distribution
```bash
# Update CloudFront distribution with new configuration
aws cloudfront update-distribution --id E2QFR8E7I4A6ZT --distribution-config file://aws-policies/cloudfront-config-update.json
```

### Configuring CORS for CloudFront/S3
```bash
# Apply CORS configuration to S3 bucket (required for CloudFront)
aws s3api put-bucket-cors --bucket your-bucket-name --cors-configuration file://aws-policies/cloudfront-cors-config.json

# Note: After updating the S3 bucket CORS, you may need to invalidate CloudFront cache
aws cloudfront create-invalidation --distribution-id E2QFR8E7I4A6ZT --paths "/*"
```

## 📋 File Organization

Files are organized by service and purpose:
- **Policy files**: Define permissions and access controls
- **Configuration files**: Define service settings and parameters
- **Backup files**: Preserve previous configurations for rollback

## ⚠️ Security Notes

- These files may contain sensitive configuration data
- Review policies carefully before applying to production
- Always backup current configurations before making changes
- Use least-privilege principles when defining policies

## 🔄 Maintenance

- Keep configurations in version control
- Document changes in commit messages
- Test policies in development environment first
- Regular review and cleanup of unused policy files
