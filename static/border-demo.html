🎨 Border Overlay System - How to Use

📍 Navigation Links

Step 1: Generate Products

First, create some merchandise previews:

  1. Go to Preview Generator
  2. Select images from your gallery
  3. Choose product types (T-shirts, mugs, etc.)
  4. Click "Generate Previews"

Step 2: Access Vendor Catalog

View your generated products:

  1. Go to Vendor Catalog
  2. See grid of product cards
  3. Each card has product info and preview image
  4. Look for "🎨 Add Border" button

Example Product Card:

Sample Product Image

Step 3: Configure Border

When you click "🎨 Add Border", a modal opens with:

  • Preview Section: Before/after comparison
  • Border Types: Solid, Gradient, Pattern, Wavelength Theme, Blend
  • Configuration: Colors, width, opacity, effects
  • Quick Presets: Classic, Fire, Ocean, Goblin, Blend
  • Real-time Updates: See changes immediately

🎯 What Each Border Type Does:

  • 🔸 Solid: Simple colored border with adjustable width
  • 🌈 Gradient: Multi-color gradients (linear, radial, conic)
  • 🎨 Pattern: Repeating designs (dots, stars, stripes)
  • ⚡ Wavelength Theme: Game-themed borders with Lore elements
  • 🌊 Blend: Smooth transitions for fabric blending

Step 4: Apply and Save

  1. Adjust settings until you like the preview
  2. Click "Generate Preview" for final preview
  3. Click "Apply Border" to save
  4. Modal closes and catalog refreshes
  5. Your bordered image is now saved!
